# OUR YEAR — 가족 사계절 포토북 아카이브

흩어져 지내는 가족들이 1년 동안 각자의 자리에서 사진을 올리면, **촬영 날짜(EXIF)와 사진 비율을 자동 인식하여 매거진·화보집 스타일의 한 권의 책으로 자동 조판**해 주는 풀스택 웹 서비스입니다.

## 주요 기능

1. **촬영일(EXIF) 자동 추출 및 월별·계절별 자동 분류**
   - 스마트폰·카메라 사진 업로드 시 `EXIF DateTimeOriginal`, 카메라 기종, 렌즈 정보, 가로/세로/정방형 비율을 자동 인식합니다.
   - EXIF 정보가 없는 카카오톡 공유 사진도 파일명 날짜 패턴(`YYYYMMDD`)이나 파일 수정일을 인식하며, 업로드 전후 언제든 날짜와 장소를 수정할 수 있습니다.
2. **매거진 화보집 자동 레이아웃 & 양면 펼침북(Flipbook) 스튜디오**
   - 사진 개수(1~4장), 비율(가로/세로), 하이라이트(`★ 메인 화보`) 여부를 분석해 단독 화보형, 비대칭 듀오, 1+2 트리오, 4분할 모던 그리드 등 매거진 레이아웃을 자동 생성합니다.
   - **양면 펼침북 뷰**, **단면 뷰**, **전체 페이지 한눈에 보기**를 지원하며, 각 페이지 우측 상단의 `레이아웃 변환` 버튼으로 페이지별 배치를 즉시 바꿀 수 있습니다.
3. **가족 구성원별 프로필 태그 & 따뜻한 한 줄 코멘트**
   - 엄마, 아빠, 큰딸, 둘째, 막내 등 가족 구성원을 자유롭게 추가·선택할 수 있으며, 사진마다 남긴 일기와 가족들의 답글 코멘트가 포토북 페이지 안에 함께 인쇄됩니다.
4. **고해상도 포토북 PDF 다운로드 & 인쇄 모드**
   - `포토북 PDF 다운로드` 버튼으로 표지·프롤로그·월별 간지·화보 페이지·에필로그가 모두 포함된 A4 규격 PDF 파일을 생성하거나, `인쇄 / 북 프린트`로 고해상도 인쇄를 실행할 수 있습니다.
5. **로컬 서버 영구 저장소 + Supabase 클라우드 실시간 연동**
   - 별도 설정 없이도 즉시 동작하는 로컬 서버 DB(`server/storage/archive.db.json` 및 `server/storage/uploads/`)를 기본 내장하고 있으며, 상단 `클라우드 설정` 모달에서 Supabase URL과 Anon Key를 입력하면 원격 클라우드 DB와 실시간 동기화됩니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3456`으로 접속하면 바로 이용할 수 있습니다.
